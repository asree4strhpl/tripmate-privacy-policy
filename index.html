Kebijakan Privasi TripMate

Tanggal Berlaku: 8 Oktober 2026

TripMate adalah aplikasi perencanaan perjalanan dengan slogan “Plan your trip. Pack smarter. Travel better.”

TripMate dikembangkan oleh Muhammad Asri. Kebijakan Privasi ini menjelaskan bagaimana TripMate mengakses, menggunakan, menyimpan, dan membagikan data pengguna ketika aplikasi digunakan.

1. Data yang Digunakan oleh TripMate

TripMate dirancang untuk meminimalkan pengumpulan data pribadi. Aplikasi tidak menyediakan pembuatan akun, login, atau profil pengguna.

a. Data lokasi

Ketika pengguna menggunakan fitur Nearby / Explore Nearby, TripMate dapat meminta akses lokasi perangkat untuk memperoleh koordinat lokasi saat ini.

Data lokasi digunakan untuk menemukan destinasi wisata di sekitar pengguna dan memberikan hasil destinasi berdasarkan posisi pengguna.

b. Data perjalanan

Pengguna dapat memasukkan informasi seperti nama perjalanan, destinasi, tanggal perjalanan, catatan perjalanan, daftar barang bawaan, serta item dan nominal anggaran.

Data tersebut digunakan untuk menyediakan fitur Trip Planner, Wishlist, Packing List, dan Budget Planner.

c. Data untuk fitur AI

Ketika pengguna menggunakan AI Smart Packing atau AI Budget Assistant, informasi yang relevan dengan permintaan pengguna dapat dikirim ke layanan AI pihak ketiga untuk menghasilkan rekomendasi.

2. Penyimpanan Data

Data Trip Planner, Wishlist, Packing List, dan Budget Planner disimpan secara lokal pada perangkat menggunakan database lokal.

TripMate tidak menyediakan server akun pribadi untuk menyimpan profil atau riwayat perjalanan pengguna.

Data lokal dapat hilang apabila pengguna menghapus data aplikasi, menghapus aplikasi, atau melakukan tindakan lain pada perangkat yang menghapus penyimpanan lokal.

3. Layanan Pihak Ketiga

Geoapify
Digunakan untuk pencarian lokasi dan destinasi, termasuk pencarian destinasi berdasarkan lokasi pengguna ketika fitur Nearby digunakan.
Open-Meteo
Digunakan untuk memperoleh informasi cuaca berdasarkan koordinat destinasi.
Pexels
Digunakan untuk memperoleh gambar yang relevan dengan destinasi yang ditampilkan dalam aplikasi.
Groq
Digunakan untuk menyediakan fitur AI Smart Packing dan AI Budget Assistant.

Penggunaan layanan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia layanan tersebut.

4. Tujuan Penggunaan Data

Data digunakan untuk menyediakan fungsi aplikasi, termasuk:

  • Pencarian destinasi
  • Fitur Nearby
  • Informasi cuaca
  • Trip Planner
  • Wishlist
  • Packing List
  • Budget Planner
  • Rekomendasi berbasis AI

TripMate tidak menjual data pribadi pengguna dan tidak menggunakan data lokasi untuk iklan berbasis lokasi.

5. Keamanan Data

TripMate berupaya menjaga data pengguna menggunakan mekanisme keamanan yang tersedia pada platform dan layanan yang digunakan.

Komunikasi dengan layanan API eksternal dilakukan menggunakan koneksi HTTPS ketika tersedia.

Namun, tidak ada metode transmisi atau penyimpanan elektronik yang dapat dijamin 100% aman.

6. Retensi dan Penghapusan Data

Data perjalanan yang disimpan secara lokal tetap berada pada perangkat selama pengguna tidak menghapusnya.

Pengguna dapat menghapus data menggunakan fungsi penghapusan yang tersedia dalam aplikasi atau dengan menghapus data aplikasi melalui pengaturan perangkat.

TripMate tidak menyimpan akun pengguna pada server karena aplikasi tidak menyediakan fitur pembuatan akun.

7. Penggunaan Lokasi

Fitur lokasi TripMate bersifat opsional dan digunakan ketika diperlukan untuk fungsi seperti pencarian destinasi di sekitar pengguna.

Pengguna dapat menolak izin lokasi. Jika izin ditolak, fitur yang membutuhkan lokasi mungkin tidak dapat digunakan.

8. Anak-Anak

TripMate tidak dirancang secara khusus untuk anak-anak dan tidak secara sengaja meminta atau mengumpulkan informasi pribadi anak untuk pembuatan akun atau profil.

9. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu untuk mencerminkan perubahan pada fitur aplikasi, layanan pihak ketiga, atau persyaratan hukum.

Perubahan akan dipublikasikan pada halaman ini dengan memperbarui tanggal berlaku.
